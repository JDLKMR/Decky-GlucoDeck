# GlucoDeck

A Decky Loader plugin that shows your current Dexcom glucose reading using Dexcom Share.

## Not a medical device
GlucoDeck is a convenience display. Do not use it for treatment decisions or as an alarm. Readings can be delayed or missing if the phone, sensor, or network drops. Use the Dexcom app and your care team's guidance.

## Build
```
npm install
npm run build
```
